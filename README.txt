Dayflow 플래너 사용 방법

1) index.html을 브라우저에서 열면 기본 플래너를 사용할 수 있습니다. 일정 데이터는 해당 브라우저의 기기 내 localStorage에 저장됩니다.
2) 사진 글자 인식(OCR)은 첫 실행 시 인터넷 연결이 필요하며 Tesseract.js CDN을 불러옵니다. 인식 결과는 자동으로 확정 저장하지 않고, 사용자가 확인한 뒤 일정으로 추가합니다.
3) 스마트폰 홈 화면에 앱처럼 설치하려면 이 폴더 전체를 HTTPS를 지원하는 정적 호스팅(예: GitHub Pages 등)에 올린 뒤, 스마트폰 브라우저에서 해당 주소를 열어 '홈 화면에 추가'를 선택하세요. PWA 설치에는 HTTPS 호스팅이 필요합니다.
4) 데이터는 브라우저별·기기별로 따로 저장되며 자동으로 기기 간 동기화되지 않습니다. 브라우저 데이터 삭제 시 일정이 사라질 수 있으니 주의하세요.
5) 현재 OCR은 글자를 읽고 일정 후보를 제안하는 기본 기능입니다. 복잡한 표에서 날짜/시간/여러 일정을 완벽하게 자동 분리하는 기능은 아니므로 추가 전 내용을 확인하세요.
